# Сонячна система · інтерактивна 3D-мапа

Навчальний застосунок з базової астрономії для дітей початкових класів.
Планети стоять там, де вони зараз насправді.

**Один файл `index.html`.** Нуль білду, нуль зовнішніх картинок.
Кладеться в репозиторій — і працює на GitHub Pages.

---

## Технічні рішення

**Пояси рахує GPU.** Орбітальні елементи кожної частинки (`a, e, i, Ω, ω, M₀`)
лежать у вершинних атрибутах, рівняння Кеплера розв’язується там-таки чотирма
кроками Ньютона від `uTime`. 3700 тіл рухаються без жодної роботи процесора,
навіть на швидкості «рік за секунду».

**Небо малює CSS.** Еквіректангулярний фон three.js робив повноекранний прохід
з `atan/asin` на кожен піксель і з’їдав ≈80 % кадру (10 → 27 fps під софтверним
рендером після заміни). Тепер градієнт — звичайний `linear-gradient` на полотні
під прозорим WebGL.

**Текстури процедурні.** Континенти Землі полігонами, смуги Юпітера
шумом fbm, кільця Сатурна з щілиною Кассіні, «серце» Плутона — усе
малюється кодом на `<canvas>` при старті. Детермінований RNG: планети
щоразу однакові.

**Масштаб з одного джерела.** Дидактичний і справжній рахуються з тих самих
реальних чисел функціями `scaleDistance`/`scaleRadius`, а константи
підставляються в шейдер поясів із того ж місця — тест ловить будь-який дрейф.

**Резервний режим.** Якщо `astronomy-engine` не завантажився (офлайн, шкільний
фаєрвол, впав CDN) — вмикається вбудований кеплерівський пропагатор на
елементах JPL Standish. Планети лишаються на місцях із похибкою в кілька
кутових хвилин; недоступним стає тільки розділ «На небі». Застосунок про це
чесно повідомляє.

**Мобілки.** DPR обмежено двійкою (1,5 на слабких пристроях), кількість
частинок удвічі менша, панель планети — нижній лист, кадр підбирається під
співвідношення сторін, `prefers-reduced-motion` вимикає обертання й робить
доліт миттєвим.

**Доступність.** Планети — справжні `<button>`, тому працює й клавіатура, і
читач екрана. Стрілки обертають, `+/−` наближають, пробіл ставить час на паузу,
`1`…`9` перелітають до планети, `Esc` закриває. Є `aria-live` статус.

## Керування ззовні

```js
const S = window.SonyachnaSystema;
S.select('mars');                     // підлетіти до Марса й відкрити картку
S.setDate('2061-07-28');              // повернення комети Галлея
S.setRate('year');                    // рік за секунду
S.setRealScale(true);                 // справжній масштаб
S.engineMode();                       // 'engine' або 'kepler'
```

## Розробка

Джерела лежать окремими файлами тільки для зручності — на виході завжди
один самодостатній HTML.

```
python3 build.py           # src/*  →  index.html + artifact.html
node test/logic.test.mjs   # 26 тестів: Кеплер, масштаб, фази, форматери
node test/render.test.mjs  # 4 конфігурації: десктоп/мобілка × світла/темна
node test/deep.test.mjs    # супутники, комета, клавіатура, резервний режим
node test/perf.mjs         # покадровий профіль по шарах сцени
```

Рендер-тести підміняють CDN локальними копіями з `.testserve/vendor/`,
тому не залежать від мережі.
