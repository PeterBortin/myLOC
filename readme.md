# ТЕРЕН

Тактичне полотно на мапі: малювати райони, лінії, сектори й радіуси, ставити позначки
APP-6, вʼязати обʼєкти звʼязками, міряти маршрути з профілем висот, вести журнал і
вивантажувати все в GeoJSON.

Візуальна мова — **SICH Design System v2 «Термінал»**: одна моноширинна гарнітура
(JetBrains Mono), чорне полотно, рамка 1px замість тіней, зелене = головна дія,
червоне = небезпека, статус завжди колір + гліф + підпис.

## Запуск

Відкрий `index.html` у браузері. Складання не потрібне — це один файл.
Потрібна мережа: тайли, рельєф і дві бібліотеки тягнуться з CDN.

## Оболонка

**Десктоп (від 900px)** — хедер, три колонки, футер:

| Область | Що в ній |
|---|---|
| Хедер | знак SICH, хлібні крихти, годинник Zulu, стан мережі |
| Колонка 1 | Журнал обʼєктів — розкривається кнопкою «журнал» |
| Колонка 2 | Вьюпорт: тулбар угорі (журнал · інструменти · я тут / відкат / повтор · шари) і мапа |
| Колонка 3 | Шари, налаштування, картка обʼєкта, картка підрозділу, вимірювач |
| Футер | гліф стану, рядок статусу, зум і курс, мережа |

Бокові колонки згорнуті в нуль і відкриваються кнопкою; закриваються дією або
хрестиком у заголовку панелі.

**Телефон і планшет (до 900px)** — мапа на весь екран, рядок стану вгорі,
панель дій унизу, панелі виїжджають знизу як шухляди.

## Інструменти

Підрозділ (APP-6) · Полігон · Звʼязок · Коло · Сектор · Лінія · Напис · Вимір.
Лінію можна вести тапами або від руки. Кола й сектори будуються з двох-трьох тапів.

Гарячі клавіші лишились, хоч в інтерфейсі більше не показуються:
`u p k c s l t r` — інструменти, `j` журнал, `g` шари, `Enter` завершити,
`Esc` скасувати, `Backspace` остання точка, `Ctrl+Z` / `Ctrl+Y` відкат і повтор.

## Дані

Усе живе в `localStorage` цього браузера (ключі `teren2.*`, `teren3.view`).
Сервера немає, обліківок немає, нічого нікуди не йде. Експорт та імпорт — GeoJSON
з кнопок у журналі.

Запуск завжди відкриває мапу на всій території України; збережений вид не
відновлюється свідомо.

## Залежності (CDN)

- MapLibre GL JS 5.6.1 — рушій мапи
- milsymbol 3.0.4 — символи APP-6 / MIL-STD-2525
- JetBrains Mono (Google Fonts)

Для офлайн- і DDIL-збірок ці три треба покласти локально, а шрифт підключити
через `@font-face`.
